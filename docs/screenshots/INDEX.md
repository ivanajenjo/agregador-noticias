# Capturas de la aplicación

Generadas con la aplicación real sobre datos de demostración ficticios (`docs/DEMO.md`, `cmd/demo-seed/shoot.js`). Los medios y sus líneas editoriales son los de `config/sources.yaml`; los sucesos, nombres y cifras de las noticias son ficticios.

Nombre: `<sección>-<escritorio|móvil>-<claro|oscuro>.png` (en el fichero `desktop|mobile` y `light|dark`). Escritorio: página completa recortada a 2400 px; móvil: primera pantalla.
